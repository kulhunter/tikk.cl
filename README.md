# TIKK® — Food & Aperitivo Studio

Sitio web oficial de pedidos de **TIKK®** en Santiago de Chile.

- **URL:** [https://tikk.cl](https://tikk.cl)
- **Stack:** HTML5 / CSS3 (Editorial Swiss Design inspirado en Emblematica) / Vanilla JS
- **Integración:** Checkout directo con formato dinámico hacia WhatsApp Business
- **Hosting:** GitHub Pages con dominio propio personalizado vía CNAME (`tikk.cl`)

## Estructura del Proyecto

```
.
├── CNAME                  # Configuración dominio tikk.cl
├── README.md              # Documentación
├── assets/                # Imágenes de productos de alta resolución
│   ├── candy_box_v2.jpg
│   ├── combo_familiar_v2.jpg
│   ├── pack_navideno_v2.jpg
│   └── tabla_sunset_v2.jpg
├── favicon.svg            # Favicon minimalista SVG
├── index.html             # Catálogo y tienda interactiva
├── robots.txt             # Directivas de indexación
└── sw.js                  # Purgado y control de caché
```
